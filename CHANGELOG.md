# Changelog

All notable changes to **REDMAGIC Control** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.8.0] - 2026-11-22

### Added
- **One-click in-place self-updater (`src/updater.rs`, `src/commands.rs`, `src/main.rs`, `panels.js`, `app.js`)**:
  - Added streaming HTTPS release download via Windows WinHTTP (`app_install_update` / `app_cancel_update`) with real-time progress bar (`MB / total · speed · %`) and download cancellation inside both the update modal and the **关于** page.
  - Strictly validates official GitHub HTTPS release URLs, verifies exact byte length and Windows PE executable headers (`MZ` + `PE\0\0`) before staging, and rejects read-only directories up front with clear guidance.
  - Performs zero-console-flash atomic replacement via the staged binary's native `--apply-update` handoff (waits for old PID exit, creates `.old` rollback backup, atomically swaps the executable, restarts the updated app with race-free single-instance handoff, and cleans up temporary artifacts automatically). All `settings.json` preferences and pinned Studio streams carry over seamlessly.

## [0.7.4] - 2026-11-22

### Fixed & Improved
- **Redesigned mouse LED preview to match real `GS001S` hardware zones and cohesive lighting (`stage.js`, `lighting.js`, `panels.js`, `catalog.rs`)**:
  - Removed the fake scroll-wheel RGB overlay (real `GS001S` only illuminates the left/right V-wing diffusers and the tail 4-blade RedMagic emblem, matching `mousedevice.xml`) and added a pixel-accurate `269×450` HiDPI alpha mask (`redmagic-mouse-led-mask.png`) with soft neon aura.
  - Replaced disjoint per-zone solid colors with a unified lighting field: `随波逐流` renders a smooth continuous vertical gradient wave across V-wings and tail Logo (honoring official `由下至上 / 由上至下` direction), `流光模式` cycles all zones together in unified spectrum harmony, and `呼吸 / 常亮` keep all zones synchronized in the chosen color.
  - Added official `由下至上 / 由上至下` direction toggle (`buf[4]`) for mouse `随波逐流` mode.

## [0.7.3] - 2026-11-21

### Fixed
- **Fixed third-party mice/keyboards being misidentified as REDMAGIC peripherals (`catalog.rs`, `manager.rs`)**:
  - Removed the generic `"mouse"` / `"keyboard"` USB product-string fallback in `match_catalog_by_hid` that caused non-REDMAGIC mice/keyboards using shared OEM VIDs (`0x320F` EVision / `0x0C45` Sonix, e.g. ATK, VGN, VXE, Redragon, Dareu, Delux, Ajazz, Glorious) with `UsagePage 0xFF1C / Usage 0x92` to be falsely recognized as `REDMAGIC Mouse 1S (GS001S)` or `REDMAGIC Keyboard 1S (GK001S)`.
  - Aligned USB/2.4G HID matching strictly with official `Goper.exe` exact `(VID, PID)` pairs (`0x320F:0x5134/0x5135` for `GK001S`, `0x320F:0x2276/0x2277` for `GS001S`), removed unofficial generic Sonix VID `0x0C45`, and routed Bluetooth HID interfaces strictly through `match_bt_catalog`.

## [0.7.2] - 2026-11-21

### Fixed
- **Fixed frozen mouse LED preview animation (`lighting.js`, `stage.js`, `styles.css`)**:

  - Upgraded mouse 3-zone LED preview (scroll wheel, V-wing guides, RedMagic tail logo) from `<svg>` DOM updates to a single lightweight `179×300` `<canvas class="ms-led-canvas">` (`drawMouseLedCanvas`) with soft neon glow and zero DOM churn.

## [0.7.1] - 2026-11-21

### Fixed & Enhanced
- **Fixed About-page preference toggles not triggering (including Windows Autostart & tray settings)**: Removed duplicate `id=` attributes generated by `toggleSwitch(...)` on the 4 switches in **关于软件** (`about-close-tray-toggle`, `about-autostart-toggle`, `about-auto-resume-toggle`, `about-auto-update-toggle`) where HTML5 discarded the second `id` so `change` handlers never matched.
- **Hardened Windows 10/11 Autostart (`src/settings.rs`)**: Synchronizes `HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\StartupApproved\Run` alongside `HKCU\...\Run` (preventing stale Task Manager disable flags from blocking autostart) and automatically refreshes the startup executable path on launch if the `.exe` was moved or upgraded.
- **Pinned Studio streaming & reliable boot / wake auto-start (`src/main.rs`, `panels.js`, `app.js`)**:
  - Added a direct **固定当前推流设置（开机自启自动开启）** control bar inside **灯效编程** so preset/layers/sliders/brightness/Logo/port settings stay pinned across restarts and temporary stops.
  - Upgraded boot auto-resume to retry cleanly for ~30 seconds across Windows USB/2.4G enumeration delays (only stopping on actual `Ok(_)`) and automatically trigger on device hotplug / 2.4G wireless keyboard wake-up!

## [0.6.0] - 2026-11-21

### Added
- **Default-on close-to-tray suspension (`closeToTray: true`)**: Closing the window now suspends directly to the Windows System Tray by default (destroying WebView2 to release all browser processes and ~300 MB RAM while idling at ~0% CPU), configurable in **关于软件**. Right-clicking the tray icon and choosing `退出程序` exits completely.
- **Native Windows Startup / Autostart (`src/settings.rs`)**: Win32 Registry (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`) toggle paired with `静默进托盘` (`--autostart`, enabled by default), booting straight into the Windows System Tray with `0.00%` CPU, `12.4 MB` working set (`2.1 MB` private RAM), zero window flash, and `0` WebView2 processes.
- **Persistent preferences (`%LOCALAPPDATA%\com.redmagic.control.rs\settings.json`)**: Saves close-to-tray, silent autostart, and auto-update preferences across restarts.

### Performance & Docs
- **Major foreground CPU (-94% to -97%) & RAM (-207 to -235 MB) optimization**:
  - Replaced 126 animated keyboard LED/Logo DOM nodes (`.kb-led` × 100 + `.logo-seg` × 26) with a single hardware-aligned `680×248` `<canvas>` layer (`drawKeyboardLedCanvas` in `stage.js`, `lighting.js`, `studio.js`).
  - Eliminated 40+ nested CSS `backdrop-filter` blur passes on top of Windows 11 DWM Acrylic (`tokens.css`) and replaced mouse SVG `feGaussianBlur` with lightweight dual-halo vector paths.
  - Replaced spinning `requestAnimationFrame` throttle loops with sleep-between-frames scheduling (`setTimeout` + `rAF`), eliminated idle polling on static `paint` mode (0% CPU), switched background loop from fixed `16 ms` to adaptive `450–800 ms` when native streaming is active, and pruned unused WebView2 subsystems (`--renderer-process-limit=1 --disable-extensions --disable-background-networking --disable-component-update`).
  - Measured foreground results (12-core Windows 11, 8s active window):
    - Keyboard Overview (Wave): **8.11% → 0.43% CPU (-94.7%)**, **621.6 → 414.4 MB (-207.2 MB)**
    - Keyboard Lighting: **8.48% → 0.23% CPU (-97.3%)**, **625.0 → 415.5 MB (-209.5 MB)**
    - Studio Live Streaming: **14.13% → 0.84% CPU (-94.1%)**, **668.0 → 432.8 MB (-235.2 MB)**
    - About (Static): **0.03% → 0.00% CPU**, **415.5 → 395.8 MB**
- **Streamlined `README.md` and UI copy**: Removed redundant implementation hype and refreshed showcase screenshots (`docs/screenshots/*.png`).

## [0.4.2] - 2026-11-20

### Fixed & Optimized
- **Eliminated abnormal background CPU (13.6% → <0.3%) & RAM (312 MB → ~15 MB) when suspended to tray**:
  - **Pure-Rust Native RGB Runner (`src/studio/runner.rs`)**: Implemented all 6 built-in presets (`aurora`, `radar`, `ripple`, `spectrum`, `ambilight`, `matrix`) and the 4-layer compositor directly in zero-allocation Rust threads feeding HID `OP 0x12 + OP 0x28` at `30 FPS` (USB wired) / `8 FPS` (2.4G) with zero per-frame JS IPC overhead.
  - **Zero-WebView2 headless tray suspension**: When suspending to tray (via `后台挂起` or window close) while using any built-in preset, multi-layer mode, or external UDP/HTTP/WS bridge, the WebView2 window is now **completely destroyed** (`win.destroy()`), releasing all 6 Chromium WebView2 processes (~312 MB RAM and 11.6% GPU CPU). Clicking the tray icon or relaunching the app (signaled via Win32 Named Event `Local\REDMAGIC_Control_RS_WakeEvent`) recreates the UI on demand and seamlessly restores the live streaming state via `studio_status`.
  - **Zero-GPU hidden mode for custom JS shaders**: Removed `--disable-backgrounding-occluded-windows` (which previously forced WebView2 GPU process to composite 60 FPS frosted-glass blur onto invisible windows), added explicit `ICoreWebView2Controller::SetIsVisible(false)` + `visibilitychange`/`studio:tray-hidden` hooks to halt all `rAF` loops and CSS animations immediately.
  - **Foreground GPU optimization**: Isolated `.stage-kb-crop` / `.kb-led-layer` with `contain: layout style paint; transform: translateZ(0)` and matched foreground Studio preview cadence to `30 FPS`.

## [0.4.0] - 2026-11-20

### Added
- **Programmable RGB Studio (`灯效编程`)** for `GK001S` with 4 unified sub-modes fitting cleanly inside `1280×820` without page scrolling:
  1. **Onboard Per-Key Static RGB Painter (`逐键涂色`, `OP 0x0a` / `OP 0x0b`)**: Click or drag-paint across all 100 physical keys (brush / right-click eraser / eyedropper), 4 independent onboard Flash slots (`group 0..3`, offset `group * 0x200`, `378 B`), and 6 quick zone templates (RedMagic, FPS WASD, MOBA QWER, Cyber Gradient, Pure White, Clear). Persists offline across Bluetooth, 2.4G, and power cycles.
  2. **JS Shader Programmable Lighting Engine + Zero-Wear Volatile RAM Streaming (`脚本编程`, `OP 0x12` + `OP 0x28`)**: Live hot-reloading `render(x, y, t, ctx) -> [r, g, b]` editor with 6 built-in presets (Cyber Aurora, RedMagic Radar, Typing Ripple, Music Spectrum, Screen Ambilight, Digital Matrix), real-time `p1/p2/p3` sliders, `.json`/`.js` preset import/export, 60 FPS UI preview, and direct volatile RAM streaming (`30 FPS` USB wired / `8 FPS` 2.4G, 100 keys `378 B` + top 20-LED Logo strip `60 B`, zero Flash wear, automatic onboard lighting restore on stop or exit).
  3. **Multi-Layer Compositor + Pure-Rust Windows System Linkage Engines (`多图层`)**:

     - `src/studio/ambilight.rs`: Pure-Rust Win32 GDI `16×6` primary screen color sampler + 20-LED top edge mapper with vibrance boost and EMA smoothing.
     - `src/studio/keyhook.rs`: Pure-Rust 60 Hz Win32 `GetAsyncKeyState` global key activity & coordinate pulse mapper for typing ripples.
  4. **Local Loopback External RGB Bridge API (`外部接口`, `src/studio/server.rs`)**: Strictly bound to `127.0.0.1`, exposing high-speed UDP (`27650`, `<1 ms` `RMGB` binary frame + JSON) and HTTP / RFC 6455 WebSocket (`27651`: `GET /api/status`, `POST /api/rgb`, `WS /ws`) with live packet/FPS telemetry, stage preview, and copyable Python starter snippet.
- **Background monitor guard during streaming**: Automatically pauses background HID telemetry polling while real-time RAM streaming is active, and restores original keyboard `light.mode` / `logo.mode` cleanly on tab switch, stop, or app exit.

## [0.3.0] - 2026-11-20

### Added
- **Pure Rust + Tauri v2 architecture**: Complete native rewrite replacing Electron and `node-hid`, producing a single ~9 MB standalone Windows executable.
- **Native Win32 Overlapped HID backend** (`src/devices/hid_win.rs`): Zero C `hidapi` dependency, `CancelIoEx` + `GetOverlappedResult` deterministic I/O cancellation and RAII handle lifecycle to eliminate heap corruption crashes.
- **Native Win32 Bluetooth BLE backend** (`src/devices/bluetooth_win.rs`): SetupAPI + CfgMgr32 direct discovery and `0x180F` battery reading without spawning PowerShell subprocesses.
- **Three-mode connection manager** (`src/devices/manager.rs`): Unified USB wired (`56B`), 2.4G wireless (`24B` chunking + `OP 0xaa` wake/sleep probing + `OP 0x50` NACK handling), and BLE read-only battery links with priority aggregation and hotplug/telemetry monitoring.
- **GK001S & GS001S full device controls**: Performance & polling rate, RGB lighting preview & capability-aware controls, physical keymap editor with factory ROM diff/reset, and 320×172 TFT mini-screen image cropper/library (`0xCE0000` wired flash upload + `ScreenFileList.ini` sync).
- **Windows 11 Acrylic + obsidian frosted glass UI**: Native DWM Acrylic backdrop and rounded corners, layered CSS glassmorphism across all UI components, compact inline header telemetry pills replacing redundant KPI cards, and unified vector SVG battery gauges with left-aligned charging bolts.
- **Startup resilience**: Windows named mutex single-instance guard, automatic fallback WebView2 data directory on `0x800700AA` busy locks, and `--probe` CLI read-only self-check mode.
